# 06 — Поиск и запись

**Русский** · [English](../06-search-and-write.md)

Агент работает с памятью через три MCP-инструмента (только чтение) и обычное создание файлов (запись). Инструменты подключаются автоматически, когда пиру выдан доступ к памяти ([02 — Быстрый старт](02-быстрый-старт.md)).

## Инструменты

### memory_search — поиск

Основной вход, когда точный путь неизвестен. На входе — запрос на любом языке; на выходе — до шести заметок, отсортированных по релевантности, с полями: заголовок, путь, тип, статус, фрагмент текста вокруг совпадения и оценка.

```text
memory_search("перезапуск MCP после обновления плагина")
→ [ { title, path, type, status, score, snippet, related[] }, … ]
```

Поиск гибридный. Базовый слой — полнотекстовый (BM25), он работает всегда и не зависит от сети. Поверх него, если подключены, добавляются векторный поиск (по смыслу) и переранжирование; результаты двух слоёв объединяются. На вес влияют: статус заметки (актуальные выше, устаревшие ниже — [04](04-жанры-заметок.md)), связи (заметка-хаб со многими ссылками получает прибавку), и происхождение (чужая оперативка идёт с весом ×0.7 — она видна, но не перебивает общее знание). Оценка на выходе относительная: у самого релевантного результата — около 1.0, остальные пропорционально.

Найдя путь, агент читает заметку обычным чтением файла — отдельного инструмента чтения в наборе нет.

### memory_related — связи вокруг заметки

Граф вики-ссылок вокруг заданной заметки на глубину 1–3 шага: что с чем связано, в какую сторону. Полезно, чтобы пройти от заметки к соседям. Ссылки из оперативки на канон в графе видны, обратные (из канона в чью-то оперативку) — нет: граф канона не засоряется личными заметками разных агентов.

### memory_map — топология хранилища

Карта канона целиком: кластеры по темам, заметки-хабы (на которые многое ссылается), мосты между темами, заметки-сироты без связей. Оперативка в карту не входит. Инструмент диагностический — им куратор находит изоляты и проверяет здоровье хранилища.

## Запись

Запись всегда прямая — в нужную папку по назначению заметки. Промежуточного приёмника черновиков нет: папка объявляет жанр, хук записи проставляет служебные поля при записи.

**В канон — прямо в папку жанра.** То, что полезно команде, агент пишет прямо в папку канона по жанру: `01_Знания/` для факта, `02_Решения/` для выбора и т. д. Папку выбирает агент (жанр виден по папке), а тип, автора, статус, заголовок и отметки проставляет хук записи в момент записи — без модели. Агент пишет самодостаточный текст, ставит минимум один тег и связи (inline `[[...]]` и блок `## Связи`). Курирование позже вычитает заметку и дополнит граф связями, которые автор пропустил ([08 — Курирование](08-курирование.md)).

**Подсказки при записи.** Сразу после записи канонической заметки хук сверяет её с хранилищем по смыслу и сигналит автору прямо в момент записи, до курирования: нашёлся близкий по содержанию возможный дубль — предупреждает (лучше дополнить существующую заметку, чем плодить параллельную); просто близкая по смыслу заметка — подсказывает поставить связь. Так дубли отлавливаются на входе, а граф прирастает связями сразу. Работает при подключённом векторном поиске (сравнение по косинусной близости; пороги дубля и связи настраиваются — [11 — Конфигурация](11-конфигурация.md)).

**В оперативку — напрямую.** Личную заметку агент создаёт прямо в своей подпапке `06_Оперативка_агентов/<своё-имя>/`. Пишет тело и два поля; остальное (заголовок, тип, дату, автора) проставит система:

```markdown
---
subtype: грабли
description: «1–2 предложения, о чём заметка»
---
Тело заметки.
```

Свою оперативку агент правит свободно — текст, статус, описание. Заголовок, тип, дату и автора система держит неизменными. При правке проставляется отметка «кто менял» — служебная метка, по которой курирование отличает правки автора, куратора и человека.

## Что агент видит в своей памяти

Своя оперативка видна в поиске без понижения веса; чужая — с весом ×0.7 (видна, но ниже). Это поведение по умолчанию для сессии с известной личностью; при административном доступе без личности понижения нет — видно всё как есть.
